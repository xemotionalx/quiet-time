# Quiet Time

A mobile app for unhurried, focused quiet time on iOS and Android.

## Prerequisites

- Node.js
- [bun](https://bun.sh)
- Xcode (iOS Simulator), Android Studio (emulator), or [Expo Go](https://expo.dev/go)

## Setup

1. Install dependencies:

   ```bash
   bun install
   ```

2. Copy the env example and fill in your Supabase project URL and publishable key (never the secret key):

   ```bash
   cp .env.example .env.local
   ```

## Run

```bash
bun start
```

Then open the app in iOS Simulator, an Android emulator, or Expo Go.
